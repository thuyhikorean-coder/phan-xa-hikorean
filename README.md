# Phản xạ khẩu ngữ HiKorean

Trang ôn tập sau khóa. `index.html` là trang đã **mã hóa bằng mật khẩu** (AES-256), nên không đọc được nội dung nếu không có mật khẩu.

Muốn thêm/sửa bài: sửa file gốc (`app-goc.html`, lưu riêng, không đưa lên GitHub), sau đó chạy `node khoa.mjs "<mật khẩu>"` để tạo lại `index.html`, rồi commit và push.
